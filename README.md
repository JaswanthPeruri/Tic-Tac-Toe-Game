# 🎮 Tic Tac Toe Game

A simple Tic Tac Toe game built using **HTML**, **CSS**, and **JavaScript**.

---

## 📖 About

This is a browser-based two-player Tic Tac Toe game where players take turns placing **O** and **X** on a 3×3 grid. The game automatically checks all possible winning combinations after every move and displays the winner with a congratulatory message. Once a player wins, all boxes are disabled to prevent further moves. Players can start a new match using the **Reset Game** or **New Game** button.

This project was developed to practice **DOM manipulation, event handling, arrays, functions, and JavaScript game logic**.

---

## ✨ Features

- Two-player gameplay (O vs X)
- Automatic winner detection
- Displays the winner with colored text
- Disables the board after a player wins
- Reset Game button
- New Game button
- Simple and responsive user interface

---

## 🎮 How to Play

1. Player **O** starts the game.
2. Players take turns clicking an empty box.
3. The first player to make three matching symbols in a row, column, or diagonal wins.
4. A congratulatory message is displayed for the winner.
5. Click **Reset Game** or **New Game** to start another match.
